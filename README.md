# VelvetStore - Website Bán Quần Áo

## Danh Mục
Web bán hàng, Full Stack

## Giới Thiệu
VelvetStore là website bán quần áo trực tuyến với hệ thống backend API và frontend cho người dùng.

## Chức Năng
- Xem danh sách sản phẩm quần áo
- Tìm kiếm và lọc sản phẩm
- Giỏ hàng và đặt hàng
- Quản lý tài khoản người dùng
- Quản lý sản phẩm, đơn hàng (admin)

## Công Nghệ Sử Dụng
- **Frontend**: React
- **Backend**: Node.js, Express
- **Database**: MySQL/MongoDB

## Yêu Cầu Hệ Thống
- Node.js v16+
- MySQL/MongoDB

## Cài Đặt
```bash
# Cài đặt backend
cd backend
npm install

# Cài đặt frontend
cd ../frontend
npm install
```

## Chạy Ứng Dụng
```bash
# Chạy backend
cd backend
npm run dev

# Chạy frontend
cd frontend
npm start
```
